# helpyy

Get out of awkward situations. Save a number of taps or a knock rhythm on the back of your phone,
pick who should "call" you, and knock it whenever you need an excuse to leave.

See [docs/features/knock_calls.md](docs/features/knock_calls.md) for how it
works.

## Running

    flutter run

Use a real phone. Simulators have no accelerometer to knock on.

## Checks

    flutter analyze
    flutter test
